# Таска #24 — Дистанция и кнопка 2GIS

## Что бэкенд теперь отдаёт

**`GET /api/v1/search`** — карточка в поиске:
```json
{
  "id": "...",
  "name": "Барбершоп Чё Как",
  "branchAddress": "ул. Абая 10",
  "latitude": 43.238949,
  "longitude": 76.889709
}
```

**`GET /api/v1/businesses/{businessId}/branches`** — список филиалов:
```json
{
  "id": "...",
  "address": "ул. Абая 10",
  "latitude": 43.238949,
  "longitude": 76.889709
}
```

`latitude`/`longitude` могут быть `null` если бизнес не заполнил координаты — обрабатывать gracefully.

---

## Что нужно сделать фронту

### 1. Дистанция на карточке

Получить геолокацию пользователя и посчитать расстояние:

```js
navigator.geolocation.getCurrentPosition(pos => {
  const dist = haversine(
    pos.coords.latitude, pos.coords.longitude,
    card.latitude, card.longitude
  );
  // показать "2.3 км"
});
```

Формула Haversine или готовая библиотека (`geolib`, `haversine-distance`).

Показывать только если `latitude != null && longitude != null` и пользователь дал разрешение на геолокацию.

### 2. Кнопка "Открыть на карте"

Deep link на 2GIS по координатам:
```
https://2gis.kz/geo/{longitude},{latitude}
```

> Важно: порядок именно `longitude, latitude` — не наоборот.

```js
const url = `https://2gis.kz/geo/${branch.longitude},${branch.latitude}`;
// открыть в новой вкладке или через Linking.openURL на мобиле
```

Кнопку показывать только если координаты есть.

---

## Edge cases

| Ситуация | Поведение |
|---|---|
| `latitude`/`longitude` = `null` | Дистанцию не показывать, кнопку карты скрыть |
| Пользователь отказал в геолокации | Дистанцию не показывать, кнопку карты оставить |
| `online_only` = `true` | Дистанция и карта не нужны |

---

## Почему не используем 2GIS API

Демо-ключ даёт 1000 запросов на месяц — недостаточно даже для теста.
Геокодинг (адрес → координаты автоматически) и встроенная карта — отложено до появления реального спроса и платной подписки.
Текущая реализация полностью бесплатна и не требует API ключей.
