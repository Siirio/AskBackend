# Architecture System Analysis Skill

Use before coding unclear or risky Ask work.

Trigger for:

- catalog;
- services;
- schedules;
- integrations;
- scaling across cities/countries;
- auth and roles;
- API contract shape;
- data ownership;
- cross-domain architecture.

Output:

```text
Problem:
Actors:
Current evidence:
Proposed model:
MVP shortcut:
Deferred decisions:
Risks:
Verification:
```

If the analysis exposes a product decision that is not approved, stop and ask before implementation.
