# Ask Skills

These are portable skill specifications. They can be read as docs or converted into installable Codex skills.

Use the smallest relevant set:

- backend code: `backend-spring-ask.md`;
- frontend/mobile/API contract: `frontend-ask.md`;
- catalog/import/search: `catalog-integration.md`;
- services/schedules: `services-search.md`;
- unclear architecture: `architecture-system-analysis.md`;
- team consistency: `ai-workflow-consistency.md`;
- lifecycle records: `mcp-dashboard-usage.md`.

Do not load every skill for every task.
