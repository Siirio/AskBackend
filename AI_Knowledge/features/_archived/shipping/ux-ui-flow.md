# Shipping & Profile — Frontend UX Expectations

## Shipping settings (business cabinet)
- Company/branch profile section → Shipping tab
- Owner sets: shipping mode (delivery/pickup/etc.), cities covered
- City multi-select from available cities list
- Simple PATCH — no complex shipping zone editor

## Customer profile
- Accessible from app settings / profile icon
- Display name, email (read-only after verification), profile icon
- Optional preferences: sizes, style, budget, city, favorite brands
- All preferences optional and editable
- Profile auto-created on first access (lazy initialization)
