# Local search demo

`seed.sql` contains fictional local-only businesses, branches, products, services, prices, and search projections. Rows marked available are demo fixtures treated as business-confirmed data; all other rows deliberately require confirmation.

The seed is intended for a fresh `ask_local_demo` database after Flyway migrations have run.

Useful searches:

- `trail running shoes under 50000`
- `wireless noise cancelling headphones`
- `laptop repair`
- `haircut under 15000`
- `phone battery replacement in Astana`
